# rag-bot

Телеграм бот который отвечает на вопросы по загруженным документам. Сделал как пет-проект чтобы разобраться как работает RAG на практике.

## Как это работает

1. Загружаешь текст боту
2. Текст разбивается на чанки и превращается в эмбеддинги через OpenAI
3. Эмбеддинги хранятся в FAISS индексе
4. Когда задаёшь вопрос — находятся похожие чанки и отправляются в GPT как контекст

## Стек

- pyTelegramBotAPI
- OpenAI API (embeddings + gpt-3.5-turbo)
- FAISS — векторный поиск
- LangChain — разбивка текста на чанки

## Запуск

```bash
git clone https://github.com/SurinTimofey/rag-bot
cd rag-bot

pip install -r requirements.txt

cp .env.example .env
# вставь свои токены в .env

python bot.py
```

## Команды бота

```
/start  - приветствие и список команд
/upload - загрузить текст
/ask    - задать вопрос по документу
/clear  - очистить загруженные документы
```

## Пример использования

1. Отправляешь `/upload` и вставляешь любой текст (статья, документация, заметки)
2. Отправляешь `/ask` и задаёшь вопрос по этому тексту
3. Бот находит нужные части текста и отвечает на основе них

## Заметки

- Документы хранятся в памяти, при перезапуске бота сбрасываются
- Нужны ключи OpenAI и Telegram Bot Token (получить у @BotFather)
